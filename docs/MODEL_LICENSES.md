# 模型来源与许可证提示

提交包保留了各模型目录原有的 README、配置文件和许可证文件。主要模型包括：Qwen2.5、Qwen2-VL、SenseVoice、FSMN-VAD、BGE-M3、BGE-reranker-v2-m3、Fun-CosyVoice3 和 Wan2.2。

比赛展示、论文附件、公开下载或商业部署前，应分别以模型目录内 README 和模型发布页面的最新许可证为准。本项目代码的打包不改变第三方模型权重的许可条件，也不代表可以把所有模型权重重新公开分发。

本提交包用于比赛评审和离线复现；如比赛平台禁止上传大模型权重，应改交 `docs/MODEL_MANIFEST.md`、哈希清单和官方模型下载说明。
