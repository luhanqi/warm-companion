# 系统架构与创新点对应关系

## 数据流

1. 用户通过 `web/` 页面登录并进行文字、语音、照片等交互。
2. `backend/app/main.py` 接收请求，认证层确认老人端/家属端权限。
3. 对话进入 `llm.py`，同时从数据库私有记忆表中检索相关经历；本地 RAG 服务负责 BGE-M3 向量和 reranker 重排。
4. 语音由 SenseVoice 转写，语言指标和可用声学指标进入认知趋势模块；只向研究模型发送聚合特征，不发送原始文本。
5. 照片由 Qwen2-VL 生成客观描述，与口述、音乐或 CosyVoice 音频共同构成记忆素材；Wan 服务可生成记忆视频。
6. 家属端观察台读取授权后的趋势、回忆和互动结果。

## 创新点落地

| 创新点 | 已实现模块 | 当前边界 |
| --- | --- | --- |
| 无感式认知健康监测 | 对话指标、个人基线、趋势比较、家属端观察、研究模型接口 | 目前属于研究性风险提示，尚未经过临床队列验证 |
| 私人记忆增强 | 数据库私有记忆、BGE 检索、重排、对话上下文、LoRA 适配器 | 个性化音色依赖用户授权的参考音频及 CosyVoice 环境 |
| 记忆时光机 | 老照片理解、口述、音频、视频任务接口和回放页面 | Wan 本地视频生成对显卡要求高，低配服务器需拆分推理节点 |

## 部署建议

- **比赛现场单机**：前后端 + 数据库运行在笔记本；按显存选择启动 RAG、语音和视觉服务。
- **低配云服务器**：只部署前后端、数据库和静态资源；模型通过 HTTPS 调用 GPU 工作站或第三方 API。
- **完整 GPU 服务器**：前后端与各模型服务分容器/进程部署，端口仅对反向代理或内网开放。
